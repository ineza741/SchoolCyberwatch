PROJECT TITLE: School CyberWatch: A Security Monitoring, Incident Detection, and Alert Platform for Secondary Schools in Rwanda.

PROJECT PURPOSE: School CyberWatch is designed to help secondary-school ICT administrators monitor selected cybersecurity events occurring on school computers.

CORE BACKEND MODULES:

1. Authentication
   Create a simple secure authentication system for School CyberWatch administrators/ICT staff.

Required functionality:

* Login
* Logout/session or JWT handling
* Password hashing
* Protected API routes
